# Anti-Slop Audit 001

Tanggal: 13 September 2026  
Mode: AFTER  
Scope: `src/app/page.tsx`, `src/app/globals.css`, `src/app/layout.tsx`, metadata, dan perilaku yang dapat diverifikasi lewat source/build.

## Design Read

Reading this as: portfolio personal untuk recruiter dan calon client, dalam visual Neo-Brutalist editorial, dengan dial ENERGY 3 / RHYTHM 3 / MOTION 2.

Direction berasal dari brief pengguna untuk mempelajari dan memakai bahasa visual neobrutalism.dev. Identitas yang terlihat adalah kertas krem, tinta hitam, hard shadow, border tebal, warna blok, tipografi Brakle, dan komposisi yang berganti antara hero, editorial text, project cards, skill list, timeline, dan contact block.

## Findings

### 1. [HIGH] Em dash masih muncul di UI dan metadata

- Rule: R-02, hard gate.
- Evidence: `src/app/page.tsx:37-38,87` dan `src/app/layout.tsx:6,11`.
- `—` muncul pada rentang pengalaman, atribusi quote, title metadata, dan Open Graph title.
- Impact: copy gagal hard gate, meskipun sebagian em dash berasal dari metadata yang tetap tampil di browser/share card.
- Suggested fix: ganti em dash dengan titik, koma, atau titik dua di seluruh text source yang dikirim ke user.

### 2. [HIGH] Focus indicator keyboard belum didefinisikan secara eksplisit

- Rule: R-32, hard gate.
- Evidence: `src/app/globals.css:38-43,65-69` tidak memiliki `:focus-visible`; style link/button hanya mengatur hover.
- Impact: fokus keyboard bergantung pada browser default dan tidak ada jaminan indikator yang jelas pada latar warna blok atau tombol.
- Suggested fix: tambahkan `:focus-visible` yang konsisten untuk link dan button dengan outline/offset yang kontras, lalu uji urutan Tab pada desktop dan mobile menu.

### 3. [HIGH] Statistik ditampilkan tanpa sumber yang terlihat dan satu angka tidak konsisten

- Rules: R-17, R-36, R-38, hard gate.
- Evidence: `src/app/page.tsx:93` menampilkan `3.58`, `07`, `02`, dan `2026` tanpa link atau konteks sumber. Data v3 memiliki 8 entri sertifikat di `CERTIFICATES`, sehingga angka `07` perlu dikonfirmasi.
- Impact: angka terlihat seperti klaim final yang tidak bisa diverifikasi dari halaman ini, dan angka sertifikasi berpotensi salah.
- Suggested fix: tampilkan hanya angka yang dikonfirmasi, ubah label menjadi klaim yang dapat diverifikasi, atau hapus stat row sampai sumbernya jelas.

### 4. [HIGH] Target sentuh menu mobile dan brand mark di bawah minimum 44px

- Rule: R-03, hard gate.
- Evidence: `.menu-button` di `src/app/globals.css:54,170-174` hanya memakai padding tanpa `min-height` atau `min-width`; `.brand-mark` di `src/app/globals.css:50` berukuran 38px dan berada di dalam link yang sangat kecil.
- Impact: kontrol utama di mobile dapat sulit ditekan dan tidak memenuhi minimum tap target 44px.
- Suggested fix: tetapkan dimensi minimum 44px untuk menu button dan area link brand, tanpa memperbesar visual mark di dalamnya.

### 5. [MEDIUM] Panah dekoratif dipakai pada hampir semua CTA/link aksi

- Rule: R-08.
- Evidence: helper `Arrow` di `src/app/page.tsx:41` dipakai pada CTA hero, seluruh link project, dan seluruh tombol contact di `src/app/page.tsx:69-70,95,101`.
- Impact: panah tidak lagi menjadi sinyal arah atau external action, melainkan pola dekoratif berulang.
- Suggested fix: pertahankan hanya pada link external atau download CV yang memang berpindah konteks; hapus dari anchor internal dan CTA yang tidak membutuhkan cue arah.

### 6. [MEDIUM] Motion loop tidak punya alasan UX yang tertulis

- Rule: R-19.
- Evidence: status dot menjalankan `animation: pulse 1.8s infinite` di `src/app/globals.css:59,155`, sedangkan ticker menjalankan `animation: marquee 24s linear infinite` di `src/app/globals.css:80,156`.
- Impact: dot Open to Work terus bergerak walaupun statusnya sudah berupa teks, dan ticker bergerak tanpa kontrol pause. Reduced-motion fallback sudah ada, tetapi tidak menggantikan kebutuhan akan tujuan motion.
- Suggested fix: hilangkan pulse pada status dot; pertahankan marquee hanya jika benar-benar membantu scan bidang kerja, atau ubah menjadi strip statis/berhenti saat hover/focus.

### 7. [MEDIUM] Simbol bintang dipakai sebagai dekorasi generik

- Rule: R-04.
- Evidence: `✳` di `src/app/page.tsx:76` dan `✦` berulang di `src/app/page.tsx:81`.
- Impact: simbol tidak memberi informasi baru dan termasuk vocabulary dekoratif generik yang mudah terbaca sebagai output template.
- Suggested fix: gunakan motif geometris Neo-Brutalist yang konsisten melalui CSS untuk identitas visual, atau hilangkan simbol ketika tidak membawa makna.

### 8. [LOW] Palette aktif melebihi batas 2-3 warna inti + 1 aksen

- Rule: R-29.
- Evidence: `src/app/globals.css:26-35` mendefinisikan yellow, blue, pink, green, dan red sebagai warna kromatik aktif; semuanya dipakai pada stat, skill, hero, dan contact block di `src/app/globals.css:70,92-95,100,123-127,144`.
- Impact: warna blok memang mendukung Neo-Brutalism, tetapi lima warna aktif melemahkan hierarchy jika tidak diposisikan sebagai sistem semantik yang terdokumentasi.
- Suggested fix: tetapkan 2-3 warna utama dan 1 aksen, atau dokumentasikan fungsi semantik setiap warna lalu kurangi pemakaian warna yang hanya dekoratif.

### 9. [LOW] Alasan keputusan visual utama belum ditulis di repository

- Rule: R-31 dan quality lock C-1.
- Evidence: belum ada `DESIGN.md` atau design decision record; alasan penggunaan grid background (`globals.css:45`), Brakle/Onest (`globals.css:1-24`), hard shadow, dan palette blok hanya dapat diinferensikan dari implementasi.
- Impact: keputusan sudah memiliki arah dari brief Neo-Brutalism, tetapi tidak cukup terdokumentasi untuk dipertahankan secara konsisten pada iterasi berikutnya.
- Suggested fix: tulis satu `DESIGN.md` ringkas berisi audience, visual language, palette, typography, dials, dan satu kalimat alasan untuk grid, shadow, cards, spacing, dan motion.

## Checks yang lulus

- R-24: semua item navbar mengarah ke section yang benar-benar ada, yaitu `#about`, `#work`, `#skills`, dan `#contact`.
- R-26: menu mobile memiliki state toggle; CTA lain punya `href` internal, `mailto`, file CV, atau URL eksternal nyata.
- R-27: tidak ada UI data-fetching/dashboard pada halaman ini, sehingga empty/loading/error state tidak applicable.
- R-28: tidak ada FAQ generik.
- R-30: visual memakai referensi Neo-Brutalism yang diminta, tetapi tidak menyalin struktur produk seperti Linear, Vercel, Stripe, atau Notion.
- R-33: tidak ditemukan script patching source/CSS. UI ditulis langsung di source.
- R-34: tidak ada theme toggle yang diklaim atau dikirim, sehingga tidak ada mode kedua yang rusak.
- R-35: `npm run lint` dan `npm run build` berhasil; production HTML juga berhasil dirender melalui `next start` dan endpoint lokal.
- R-18/R-22: tidak ada testimonial fiktif atau ilustrasi generik; foto profile dan screenshot project berasal dari aset v3.

## Verification limitation

Audit ini dilakukan lewat source inspection, build, dan render HTTP lokal. Tidak ada browser automation tersedia di sesi ini untuk merekam click-through visual secara pixel-level. Perilaku mobile menu dapat diverifikasi dari state `menuOpen` dan `onClick`, tetapi belum diuji dengan perangkat fisik.
