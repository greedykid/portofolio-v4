# Portofolio V4

Portfolio personal Rizki Arbiansyah dengan visual Neo-Brutalism.

## Stack

- Next.js 16.3.5
- React 19
- TypeScript
- CSS custom dengan font Onest dan Brakle

## Menjalankan project

```bash
npm install
npm run dev
```

Build production:

```bash
npm run lint
npm run build
npm start
```
